# Lessons Learned

## Linux Administration

This lab reinforced the importance of understanding how networking, services, permissions, and security controls work together in a Linux environment.

## Layered Security

Apache access depends on multiple layers working correctly, including the service configuration, firewall rules, SELinux policy, and file permissions.

## Automation

Using Bash scripts for synchronisation and backups showed how repetitive administration tasks can be automated reliably.

## Recovery Readiness

Backup files should always be validated. A backup is only useful if the required data is actually present and recoverable.

## Documentation

Clear documentation makes the environment easier to troubleshoot, rebuild, and explain to others.
